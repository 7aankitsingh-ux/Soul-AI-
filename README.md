Soul AI 🤖

Soul AI is a small AI assistant project built using the Qwen Large Language Model (LLM). The project focuses on experimenting with LLM customization, training, prompt engineering, and AI development with the long-term goal of creating my own personalized Soul LLM.

✨ Key Features
🤖 AI chatbot powered by Qwen LLM
🧠 Experimenting with LLM training and fine-tuning
💬 Natural language conversation
🎯 Customized AI personality and behavior
🔬 Testing different prompts, datasets, and model configurations
🛠️ Modular structure for future AI features
🚧 Continuous development and experimentation
🌱 Long-term goal: Develop a customized Soul LLM
🛠️ Technologies
Python — Core development
Qwen LLM — Base language model
LLM / Generative AI — AI architecture
Natural Language Processing (NLP) — Language understanding
Machine Learning — Model experimentation and training
Git & GitHub — Version control and project management
